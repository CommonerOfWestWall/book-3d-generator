# v1.3.0 Release Notes / 发布说明

**Date / 日期:** 2026-10-12

**Status / 状态:** Stable release / 稳定版

Version `1.3.0` adds thickness scaling, adjustable perspective and subtle spine shading to the Tauri desktop application. / `1.3.0` 为 Tauri 桌面程序新增书厚拉伸、可调透视和书脊淡阴影。

## Highlights / 重点

- Session-only spine thickness is available for both closed paperback and closed flat-spine hardcover: `50%`–`300%`, step `5%`, default `100%`. Saved views do not store thickness; restart restores `100%`. / 两种闭合书型均支持仅当前会话的书厚调整：`50%`–`300%`，步长 `5%`，默认 `100%`。保存视角不记录书厚，重启恢复 `100%`。
- Perspective controls support FOV `10`–`70`, default `35`, and horizontal/vertical vanishing-point offsets `-40`–`40`, default `0/0`. Automatic retreat preserves rotation and height. / 透视控制支持 FOV `10`–`70`、默认 `35`，以及水平/垂直消失点偏移 `-40`–`40`、默认 `0/0`。自动退远保持旋转和高度不变。
- Saved views use eight fields: `az`, `el`, `rotZ`, `zoom`, `height`, `fov`, `vanishX`, `vanishY`. Legacy five-field records receive `35/0/0`; v2 reads v1 only when the v2 storage key is absent and does not overwrite old storage. Built-in views reset to `35/0/0`, and batch export restores all eight fields. / 保存视角使用 8 个字段：`az`、`el`、`rotZ`、`zoom`、`height`、`fov`、`vanishX`、`vanishY`。旧版五字段记录补 `35/0/0`；v2 仅在 v2 存储键不存在时读取 v1，且不覆盖旧存储。内置视角重置为 `35/0/0`，批量导出恢复全部 8 个字段。
- The exact `书脊淡阴影` checkbox is off by default. It uses a subtle center-original, darker-edge vertex tint for both book types, preview, PNG/JPG export and batch export; it does not blur or change source images. The option is session-only. / 精确标签 `书脊淡阴影` 默认关闭。它对两种书型、预览、PNG/JPG 导出和批量导出使用中心原色、边缘较暗的轻微顶点色调；不模糊或修改源图。该选项仅在当前会话保留。

## Migration / 迁移

Version `1.3.0` reads the legacy v1 saved-view record only when the new v2 storage key is absent and fills missing projection fields with FOV `35` and offsets `0/0` in memory. Initial reading does not write storage; changing saved views or batch selections writes the normalized v2 record separately. The old storage is not overwritten, and later changes in the old build are not synchronized. / `1.3.0` 仅在新版 v2 存储键不存在时读取旧版 v1 保存视角，在内存中使用 FOV `35`、偏移 `0/0` 补齐投影字段。首次读取不会自动写入；用户修改视角或批量选择时才将规范化的 v2 记录写入独立存储。旧存储不会被覆盖，旧版后续改动也不会同步。
