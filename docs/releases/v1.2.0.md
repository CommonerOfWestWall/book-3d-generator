# v1.2.0 Release Notes / 发布说明

**Date / 日期:** 2026-10-10
**Status / 状态:** Stable release / 稳定版

This release packages the hardcover, crop, workflow, saved-view and export improvements as the stable `1.2.0` product release.

本版本将精装、裁切、工作流、保存视角和导出优化整合为稳定版 `1.2.0`。

## Upgrade Highlights / 升级重点

- Tauri 2 lightweight Windows x64 desktop path; normal startup has no black console window. / Tauri 2 轻量 Windows x64 桌面路径，正常启动不显示黑色控制台窗口。
- Closed flat-spine hardcover geometry now accounts for board thickness, overhang, spine joint and page inset estimates. / 闭合平直书脊精装现在包含板厚、出飘、书脊接缝和页面内缩估算。
- Outer-flap crop boundaries, transactional cancel/restore behavior, sRGB texture handling and export-readiness checks. / 外勒口裁切边界、事务性取消/恢复、sRGB 纹理处理和导出准备检查。
- Four tabs: `封面` Cover, `书型` Structure, `视角` View and `导出` Export. / 四个标签：`封面`、`书型`、`视角`、`导出`。
- Common four and recommended six product-view sets. / 常用四张与推荐六张商品视角。
- Named saved views with five camera fields: X/Y/Z rotation, distance and height; full CRUD and local persistence. / 命名保存五个相机字段：X/Y/Z 旋转、距离和高度，支持完整 CRUD 与本地持久化。
- Mixed built-in/custom batch export restores the original view after completion, failure or cancellation. / 内置与自定义视角可混合批量导出，结束、失败或取消后恢复原视角。

## Runtime Notes / 运行说明

- WebView2 is required but not bundled. The standalone EXE needs an existing runtime; the installer defaults to downloading the bootstrapper when the runtime is missing. Offline systems should install it beforehand. / WebView2 为必需运行时，但不内置于包中。独立 EXE 需要系统已有运行时；安装包默认在缺失时联网下载引导程序，离线环境请提前安装。
- Unsigned builds may show a Windows security warning. Do not disable antivirus software to work around it. / 未签名构建可能显示 Windows 安全警告；不要通过关闭杀毒软件规避。
- Views and batch selections use local storage for the current Windows user and application identity `com.book3d.generator`. They are not uploaded, do not travel with an `.exe` folder and do not automatically migrate between computers. / 视角和批量选择按当前 Windows 用户及应用标识 `com.book3d.generator` 使用本地存储，不上传，不随 `.exe` 文件夹迁移，也不自动跨电脑迁移。
- This tool creates presentation mockups, not print-production files. It does not provide open-book, rounded-spine or dust-jacket models. / 本工具生成展示用样机，不是印刷生产文件；不提供开书、圆脊或书衣模型。

## Developer Checks / 开发检查

`npm test`, `npm run test:ui` and `npm run check:release -- v1.2.0` cover geometry, view persistence, browser workflows and release metadata. Tag builds produce Tauri Windows downloads rather than Electron bundles. / 上述命令覆盖几何、视角持久化、浏览器工作流和版本元数据；标签发布流程构建 Tauri Windows 下载包，不再发布 Electron 包。
