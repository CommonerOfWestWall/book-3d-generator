# Version 1.3.0 Preparation Plan

**Goal:** Promote the approved thickness, perspective and spine-shadow additions to local version 1.3.0 with consistent metadata and bilingual instructions.
**Architecture:** Keep existing Tauri/Three.js behavior and application identity. Update only application versions, release guards and current documentation; preserve historical release records.
**Tech Stack:** JavaScript, npm, Rust, Tauri 2, existing Playwright/WebView2 checks.

## Scope
- package.json/package-lock.json: application and root package versions only.
- src-tauri/Cargo.toml/Cargo.lock/tauri.conf.json: application versions only.
- renderer/index.html: metadata, title and version badge.
- tests/release.test.cjs: expect 1.3.0; mismatched tags must still fail.
- README.md, CHANGELOG.md, docs/product-views.md, docs/releases/v1.3.0.md: current bilingual instructions and unpublished status.
- Existing 1.2.0 release notes, previous local EXEs and GitHub downloads remain unchanged.
